# Cafetería Luca

Página web de una cafetería local ecuatoriana, hecha con HTML y CSS puros.

## Qué incluye

- **Menú** con las bebidas y los postres.
- **Horarios de atención** en una tabla de datos.
- **Formulario de pedido online** con validación nativa y sugerencias mediante `datalist`.
- **Contacto** con dirección, teléfono y correo.

## Características

- HTML semántico.
- Tipografía fluida con `clamp()` y colores definidos como variables CSS.
- Accesibilidad: labels asociados, foco visible, navegación con teclado y enlace para saltar al contenido.
